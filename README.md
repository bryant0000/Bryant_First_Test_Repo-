# CASHFLOW 101 · 经典机制网页游戏

中文单机/同屏多人网页游戏。目标为 CASHFLOW 101 经典版；现采用自行检索取得的经典在线版组件事实与自编中文说明，具体证据和版本差异见 [SOURCES.md](SOURCES.md)。

## 运行与下载测试

聊天中的 HTML 文件链接是文件可视化入口，不能保证以完整网页方式执行游戏。若遇到“可视化内部错误”，使用以下任一方式。

### 下载离线版

下载 `dist/cashflow-offline.zip`，先解压，再用 Chrome、Edge 或 Firefox 打开其中的 `cashflow-offline.html`。这是单文件版本，CSS、数据和脚本均已内嵌，不需安装运行环境、依赖或启动服务器。浏览器若禁止本地存储，当前局仍能游玩，但不能跨刷新保存。

重新生成离线包：

```sh
python3 scripts/build-offline.py
```

### 开发服务

在仓库目录执行（Node.js 18+，无需 npm install）：

```sh
npm run dev -- --host 0.0.0.0 --port 3000
```

浏览器访问运行该命令的机器的 3000 端口。服务提供 HTML、脚本、样式、离线包及 `/healthz` 健康检查，不会展示目录列表。可用 `--port` 或 `PORT` 调整端口。没有外部字体、图片或运行期接口依赖。

也可继续使用：

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

## 玩法与组件

1. 选择 1–6 人、职业和梦想，也可点击随机发放职业卡。
2. 查看职业财务表；初始现金是一次性储蓄加月现金流。
3. 掷骰沿内圈移动，经过发薪格自动结算；处理机会、市场、慈善、添丁、失业和额外支出。
4. 从机会格选择小买卖或大买卖，管理股票、房产、企业、土地及收藏品。公开报价可供符合条件的其他玩家响应；同屏玩家可协商交易整项资产。
5. 用银行千元单位借款、部分归还银行贷款或全额偿还职业负债，调整现金流。仅现金危机时开放按半首付的银行清算。
6. 被动收入严格超过支出即进入快车道；增加 50,000 现金流或购买开局选定梦想获胜。
7. 每次完成事件后明确结束回合，交给下一位。所有玩家的资产、财务表、当前事件、牌堆和轮序自动存档。

组件库：12 种职业；55 张小买卖、40 张大买卖、45 张市场、42 张额外支出；23 个梦想；24 格内圈、48 格外圈。玩法说明页可直接查看这些数据。

目前同屏轮流游玩，不含远程联机。部分实体版差异和一张亲属赊购卡的时点尚未核实，未宣称原版逐项完整复制；详见来源记录。金额沿用资料的美元单位，是游戏数值，不构成投资建议。

## 存档

存于当前浏览器的 `localStorage`。v3 使用新键 `cashflow-classic-table-v3`，保留之前示例版本的存档键，不静默改写旧职业和旧回合数据。清除浏览器数据会删除进度；没有跨设备同步。

## 检查

```sh
node --check reference-data.js
node --check engine.js
node --check table.js
node --check app.js
node --test engine.test.cjs
```

测试包括职业开局金额、洗牌无放回、跨圈发薪、证券部分出售与拆并、抵押结清、银行还款、条件支出与分期、失业和慈善、现金危机、快车道检定及胜利、共享报价和交易，以及逐张 182 张卡的数值安全检查。

数据由 `scripts/build-reference-data.py` 从指定本地研究 checkout 读取 JSON 后生成。原始文件哈希、固定来源提交记录于 `reference-manifest.json`；游戏运行时不需要该 checkout。

原有 `main.c` 和 `test.c` 保持不变，网页不依赖它们。
