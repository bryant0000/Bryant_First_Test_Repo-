# 现金流 v0.6.0 测试版

中文网页实现，支持同屏轮流和不同浏览器联机。当前依据官网经典在线版的公开机械数据及实际游戏观察完善规则，并采用其公开棋盘、纸张和图标资源对齐视觉；尚未通过完整内容、交互和页面一致性验收。最新核对范围见 [audit/README.md](audit/README.md) 与 [SOURCES.md](SOURCES.md)。

## 运行

Node.js 18+，不需要安装运行依赖：

```sh
npm run dev -- --host 0.0.0.0 --port 3000
```

打开服务器的 3000 端口。联机玩家需要访问同一个服务地址。默认进入联机房间，也可以选择“同屏游戏”。`/healthz` 提供健康检查。

联机由本服务校验和结算指令：房间支持 1–6 人，可设置密码；全部玩家加入并准备后由房主开始。只有当前玩家能操作，重复或过期的指令会被拒绝。客户端不接收剩余牌序；刷新后恢复自己的房间和座位。房间与牌局保存在 `.cashflow/rooms.json`，服务重启时恢复；此目录已加入 Git 忽略。可以用 `CASHFLOW_ROOMS_FILE` 指定存档文件。

使用静态服务器或直接打开 HTML 时，只能使用同屏模式。联机需要上述 Node 服务，不能仅用 `python -m http.server` 提供接口。

## 当前经典流程

- 默认随机发放职业，同一局允许相同职业；同屏模式也允许指定职业。开局现金只有一次性储蓄。
- 每位玩家第一次轮到自己时选择梦想，然后处理其共享卡队列，再开始掷骰。
- 经过发薪格自动结算，停下后处理机会、市场、慈善、添丁、失业或额外支出。
- 买卖证券使用独立的份数卡。现金不足时先确认借款，返回原卡后再次确认交易。
- 在开始或结束回合选择还款，再从财务表点选负债。职业债务全额结清，银行贷款按整千部分偿还。
- 被动收入严格超过支出时确认进入快车道，并自动交棒。休整回合直接确认跳过，不掷骰。
- 快车道新增现金流达到 50,000，或支付自己选定的梦想费用时获胜。

含 12 种职业、55 张小买卖、40 张大买卖、45 张市场、42 张额外支出、23 个梦想、24 格内圈和 48 格外圈。机械字段与官网资源的比较不等于全部卡牌文字、美术和交互均已核验。

## 验证

```sh
npm test
npm run test:reference:browser
npm run test:browser
npm run test:online:browser
npm run test:layout:browser
npm run release:check
```

浏览器测试需要 Playwright 和 Chromium，测试服务可用 `CASHFLOW_TEST_URL` 指定。联机测试用两个隔离的浏览器会话验证房间、轮序、借款、存档恢复及退出；不会进入其他人的房间。

`release:check` 当前应失败：完整一致性尚未成立。当前按用户要求提供阶段测试包 `dist/cashflow-preview-v0.6.0.zip`，包含最新源码和离线文件；这不代表完整一致性验收通过。开发构建命令 `npm run build` 不代表通过一致性验收。

联机房间支持聊天及暂离后用同一浏览器恢复。刷新时短暂连接失败会保留房间会话并重试；恢复期间暂停操作，避免在本地误结算。运行服务时应保留 `.cashflow/rooms.json`，它不应提交到代码仓库。

使用 `npm run build:preview` 生成阶段测试包；解压后先读“开始游戏.txt”。本版本变更见 [RELEASE-NOTES.md](RELEASE-NOTES.md)。
