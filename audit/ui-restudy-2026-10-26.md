# 再次对照原版的修改记录

## 原版操作观察

重新打开官方经典站，在自己创建的私人房间正常操作 45 次、10 回合，记录梦想选择、开始回合、借款、结束回合、选择买卖、房产和股票报价。另独立观察顶部退出卡的打开与取消；未写入原站游戏状态、读未来牌序或访问他人房间。中文参考站可打开登录首页，但需要统一账号，未进入登录后的游戏。

## 本轮修正

- 木纹改为原尺寸绘制并由舞台裁切；此前整图缩小造成纹理错位。
- 六个玩家栏按原模板的独立横坐标排列，修正首个玩家栏偏移及姓名颜色。
- 房产卡按价格、现金流、首付三项显示，移除原版该卡没有列出的额外抵押贷款项。
- 事件标题修正为 16px，避免旧样式将其覆盖成 19px。
- 财务表按文本列绘制分段线；间隔列留白，修正分组空行、首行线及负债字体粗细。被动收入标签随进度箭头移动。
- 报表标题条原版透明度为 0.8，修正此前 0.9。
- 退出确认改为顶部纸张与托盘上的是／否操作，不遮罩棋盘；打开和取消均为原版的一秒 quint 缓动。取消保留当前回合、卡片和财务状态。

## 验证边界

`visual-region-fixtures.json` 中的 4 个 RGBA 摘要来自本次原站实际截图，坐标转换为舞台坐标；不是从本程序输出生成。当前选取的棋盘、木纹、纸张和退出托盘区域逐像素相同。相关测试也检查六个玩家栏、标题字号、房产信息顺序、报表分组及退出取消路径。截图见 `screenshots/ui-2026-10-26/`。

这不证明全部页面、全部文字、声音和罕见分支完全一致。中文文本与原站英文仍会产生换行和字形差异。完整原版等价发布门槛保持关闭；没有将旧 v0.6.1 下载文件替换为声称完成的版本。


## 继续修正（v0.6.2）

正常私人房间中，律师实际点击掷骰 37 次，观察快车道税务、风险和现金流胜利；另一局通过正常借款、购买、出售观察破产、债务减半、出局及全员结束。循环采样次数不是回合数，详见运行证据。梦想胜利尚无正常原站运行证据。

本轮增加选定财务数字与卡片按钮的独立截图摘要。原站 `ButtonElement` 按模板缩放到 110 × 44，银行按钮为 90 × 30；退出抽屉使用 `fetchSprite`，仍保持原生 0.5 缩放。改用 Canvas 变换矩阵后，选定银行与主按钮边缘区域也通过精确 RGBA 摘要。

修复慈善按钮图案与点击区域错位、房产总价栏误用首付、旁观者输入和托盘、破产出售图标、市场无匹配图标、风险结果信息、结局直接退出。补齐原音频及报表开合与还款的原站触发时机。

入口实图比较发现并修复：透明标题图露出木纹、标题背后房间列表文字可见、玩家边框缺少 #9E9380 着色，以及旧 CSS 使说明变成棕色。选定创建／等待方框及纸张边缘严格逐像素相同。标题大图区域为 1024 × 640，排除版本和提示文字，与原站截图仍有最多 1 个色阶差异，使用明确的局部容差；没有放宽其他区域的摘要检查。完整原站标题截图按原文件保存于 reference-captures/title.png，并核验文件哈希。

在线服务与离线单文件运行同一批界面检查；单文件重新构建后再测，记录见 interface-verification-2026-10-26.json。测试只能证明列出的路径与区域，不能证明整套游戏完全一致。
