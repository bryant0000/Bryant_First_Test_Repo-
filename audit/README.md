# 原版一致性验收：当前未通过

已通过官网正常界面，在自己的私人单人房间操作医生、护士和机械师；未使用账户凭据或加入他人房间。机械师一局观察 203 回合、1,200 次操作、22 类卡牌界面。观察记录不等于这些界面已通过完整一致性验收。机械事实与证据哈希见 [official-runtime.json](official-runtime.json)。

官网公开资源与固定镜像比较：9 个 JSON 一致，29 个选定回调函数体一致。独立数字夹具覆盖 182 张牌与 41 个梦想／投资内容格；机制夹具不包含整套卡牌长文。视觉层自 v0.6.0 起采用官网公开原始图集，来源见 assets/reference/SOURCES.json。这些比较不能证明实体版次、全部规则或页面一致。

实测已用于修正初始储蓄、官网缺失教育贷款的初始化、逐人首回合选梦想、偿债选择卡、股票份数卡、差额贷款返回卡牌及桌面财务表布局。特别是股票借款后，原站返回买入卡时数量重置为 1；之前“保留份数”的推断已纠正。黄金出售另有官网结算错误：持有 10 单位、报价 600，实际只入账 600；本程序仍按卡面意图入账 6,000，等待用户对复现标准的选择。

已实现独立 Node 联机服务：私人房间、准备、服务端轮序／金额校验、重复指令防重、磁盘存档、聊天、暂离和同会话恢复。刷新时暂时无法连接会保留会话并重试，恢复期间阻止本地操作结算。90 秒暂离阈值是本程序的实现选择，尚未证明与原站一致。

当前 348 项自动测试及经典页面、旧存档、双浏览器联机三套回归通过，详情见 [validation-latest.json](validation-latest.json)。
