# v0.6.3 本地页面缺陷修复

用户入口：下载完整包，解压后直接打开 index.html。

## 原因与修复

1. 财务报表的 DOM 开关没有通知 Canvas 重画。已在对话框打开和关闭时立即同步重绘；新增检查在实际点击后直接比较画布区域，未通过额外 render 掩盖缺陷。
2. 固定布局 CSS 强制显示 #reference-sheet，进入快车道后旧报表的标签还留在页面。现在只显示当前报表；老鼠赛跑、快车道与旧式表格互斥。
3. 快车道“获胜条件”中文宽度超过原英文标题，挤到右侧说明。已移到左栏，并检查两栏边界。
4. 经典模式跳过旧骰子浮层，没有任何可见的掷骰结果。新增矢量骰点、650ms 动画和点数合计；财务表展开时骰子放在右侧空位，不与报表或事件卡叠放。
5. 旧完整包 index.html 使用外部图片和字体。直接文件打开可能遇到资源策略限制；字体加载 Promise 拒绝还会阻止整个画布启动。完整包 index.html 已内嵌脚本、样式、图片、字体与音频；本地文件使用本机房间，HTTP 服务保留联机。字体拒绝时使用备用字体继续初始化。

## 验证

353 项单元测试和 24 套浏览器检查全部通过，记录见 display-fixes-v0.6.3.json。包括 12 种职业、报表即时打开／收起、快车道互斥、中文标题、1–3 骰子的动画与最终点数、报表展开期间骰子仍可见、字体拒绝、手机固定画布、卡片、终局、音效、建房、旁观者、存档恢复、旧模式及真实双浏览器联机。

测试服务来自实际完整包的解压目录，在线使用该目录的 Node 服务；index.html?offline=1 与 cashflow-offline.html 在禁用所有额外网页资源及接口的情况下验证完整离线流程。离线参数仅用于显式选择本机房间，本地 file: 协议会自动选择同一个适配器。

环境策略仍阻止自动导航 file://，因此没有声称已进行真实双击入口的自动化验证。验证了完整包内 index.html 没有外部脚本或样式引用、字体已内嵌，并保存受测 index／离线 HTML 的哈希。最终打包时再次核验这些哈希。
