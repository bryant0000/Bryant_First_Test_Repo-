# 离线界面修正记录

本轮代码尚未作为“与原版完全相同”的最终版本发布。dist 中旧版下载保持原状。

- 离线单文件入口统一为标题 → 房间列表 → 建房 → 等待 → 梦想 → 回合。
- 本机房间支持存档、恢复、多人同机交接；隐藏密码及剩余牌序，拒绝过期指令，存储被禁用时保留内存运行。
- 数值坐标来自官网公开模板和自己私人房间的正常操作观察；独立 Canvas 绘制原图集，文字和控件保留 DOM。
- 移除重复回合面板，修正原生图集缩放、报表透明度、卡片按钮位置、棋子与梦想标记位置、聊天展开方式及快车道报表。
- 退出后窗口变化不再读取空玩家状态。

验证命令：

```sh
npm test
npm run test:reference:browser
npm run test:browser
npm run test:online:browser
python3 scripts/build-offline.py --output /tmp/cashflow-entry-study
# 为构建目录启动 HTTP 后，设置 CASHFLOW_TEST_URL 指向单文件：
npm run test:standalone:browser
CASHFLOW_EMBEDDED_ONLY=1 npm run test:layout:browser
```

单元测试 351 项。浏览器检查覆盖经典规则流程、旧存档、双浏览器联机、离线入口和 13 种卡片几何与点击目标；不证明完整的逐像素或全卡牌文案等价。单文件测试阻断所有外部资源及 API 请求，并显式走 standalone 分支。浏览器策略禁止 file:// 自动导航，未将 HTTP 模拟检查冒充直接本地文件自动验证。
