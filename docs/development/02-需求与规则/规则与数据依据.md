数据字典最低要求：职业含ID、工资、税、其他支出、每孩支出、储蓄、债务余额／月供；卡牌含 sourceId、牌堆、类型、名称、成本／首付、贷款、收入、适用条件、效果及来源；资产含实例ID、类型、数量、总成本／总价、债务与收入。字段含义须以当前代码和测试逐项核对，不能按中文名字推断。

新增或变更数据必须附：来源版本、记录ID、原字段、映射字段、计算单位、边界值、预期结算、独立测试和差异说明。金额模型当前使用 JavaScript 数值；扩大数值范围时需审查安全整数范围与输入边界。

待确认决策：实体经典规则书版次；黄金10单位×600的卡面意图6,000与官网实际600差异；中文与原英文排版如何验收；官网遗漏教育贷款等行为是否属于兼容范围；多骰逐页位置与罕见事件的完整证据。未决项进入验收阻断或明确豁免，不得悄悄替换规则。
