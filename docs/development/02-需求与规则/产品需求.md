# 产品需求基线（补建，待评审）

目标：中文经典现金流网页游戏，支持离线同屏与在线房间。用户当前主要入口是完整包解压后双击 index.html；不能只验证开发服务器。当前参照官网经典在线版，不将它自动等同于已核实的实体 CASHFLOW 101 版次。

|需求ID|需求与通过条件|设计／实现入口|测试／证据|
|---|---|---|---|
|REQ-001|完整包 index 离线启动，无外部字体、图片、脚本或接口依赖；具备本机房间|构建脚本、online.js、local-rooms.js|standalone-smoke；index-local 日志；真实 file:// 仍待验证|
|REQ-002|职业、卡牌、资产、负债、收入和现金按选定规则结算|engine.js、reference-data.js|engine／reference／reference-decks 单元测试|
|REQ-003|开局、选梦想、掷骰、事件、结算、结束回合、快车道及胜负贯通|table.js、interaction.js|reference-ui、terminal-ui 浏览器测试|
|REQ-004|页面文字与金额不重叠、操作可点击，报表互斥且开关正确|classic-stage、scene-canvas、reference-ui|display-bugs、attachment-regressions；95张买卖牌边界扫描|
|REQ-005|不同浏览器加入同一服务房间，服务端校验轮序和金额|online.js、scripts/rooms.cjs|rooms 单元测试、online／observer 浏览器测试|
|REQ-006|保存、刷新恢复、短暂断网恢复；失败时不重复结算|本机存储及服务端房间存档|local-rooms／rooms、online 测试|
|REQ-007|检查完整棋盘时不结算、不丢失交易输入；返回恢复卡片|interaction.js、scene-canvas.js|attachment-regressions|
|REQ-008|原版素材和位置的对照有来源，推断项独立列出|SOURCES.md、assets/reference/SOURCES.json|audit/dice-layout-fixtures.json、视觉区域夹具|
|REQ-009|交付包有版本、测试记录、已知差异及校验值|scripts/build-preview.py、dist|audit/validation-latest.json、ZIP SHA-256|

离线为同一设备轮流操作，不承诺离线跨设备联机。在线需要 Node 服务，静态 HTTP 托管本身不提供房间接口。暂不承诺账号体系、排行榜、云端跨浏览器存档或大规模匹配服务。

非功能目标：核心数值正确、非当前玩家不能操作、未确认交易不结算、刷新不产生重复指令、字段适应允许的金额范围。浏览器／系统矩阵、并发容量及性能数值尚未形成正式批准指标，必须在最终验收前补实测目标，不能默认无限兼容。
