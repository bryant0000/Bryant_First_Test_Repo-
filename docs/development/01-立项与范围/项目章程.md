# Cashflow 项目章程

基线：v0.6.4；补建日期2026-10-27；状态：待评审。

目的：提供中文现金流经营网页游戏，支持完整包本地打开与Node服务联机。用户重点要求经典规则、原版交互和显示、可直接解压试玩、修复后进行回归。

参照对象：CASHFLOW 101经典版及官网经典在线游戏；实体版次、在线版与中文站之间不可默认完全相同。原版全等目标尚未验收。

当前范围：1–6人、本机轮流、服务端房间、职业与卡牌、资产负债表、内外圈、存档恢复和胜负。账号系统、匹配排行、大规模并发没有已批准承诺。

职责：产品负责人确认范围与遗留差异；策划核规则；技术负责人维护架构；前后端实现；设计维护页面规范；QA验证；发布责任人核对包；用户进行UAT。实际人员、预算、工期未指定，保持待确认，不虚构任命。

阶段里程碑：范围基线→规则与页面基线→技术契约→可玩单回合→单机闭环→联机恢复→质量候选→实际入口验收。已有代码不等于这些历史门禁已获批准。
