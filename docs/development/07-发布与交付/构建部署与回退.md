# 构建与交付手册

当前版本从package.json读取。Node服务不需安装运行依赖；浏览器自动化测试另需Playwright和Chromium。

1. 在确定的代码提交上运行适用测试，记录环境与日志。
2. `npm run build:preview`生成阶段完整包与内嵌HTML；它不表示原版全等验收通过。`npm run release:check`仍用于检查更强的全等门禁。
3. 解压实际ZIP进行检查：本地index、cashflow-offline、本机保存／刷新；在线用`node scripts/serve.cjs --host 0.0.0.0 --port 3000`启动，再使用两个浏览器操作。
4. 核验/healthz，核对包内HTML与受测文件SHA，记录下载地址、版本、提交和已知问题。
5. 保存原存档和旧发布包后再升级。配置、公开域名、TLS、代理及访问容量需要按实际环境验证，不把推送代码当成部署成功。

默认在线存档在.cashflow/rooms.json；可由CASHFLOW_ROOMS_FILE指定。回退前停止写入、备份数据；只有已证明旧版本可读取的存档才能直接回退。当前尚无完整跨版本迁移／回退演练结论。

发布记录字段：提交、版本、构建命令、Node／浏览器版本、配置、测试报告、包SHA、部署／下载地址、健康检查、备份位置、回退步骤、执行人与时间。实际人员签字不得由模板代填。
