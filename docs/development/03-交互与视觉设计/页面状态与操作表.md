# 页面状态与操作表

|页面组|输入／状态|主要操作|退出／异常|验收重点|
|---|---|---|---|---|
|标题与房间|未入局、容量、房名、密码|创建／加入|密码错误、房间不存在|本地与在线入口、字体资源|
|等待与梦想|座位、准备、职业、梦想ID|准备／开始／切换梦想／确认|房主关闭、重复开始|权限、轮到谁选梦想|
|开始与移动|active、rolled、lastDice|借还款、选择骰子、掷骰|非当前玩家、休整|重复掷骰、骰点与位置|
|机会与交易|pending类型、资产、现金|买入／卖出／份数／取消|不足现金进入贷款子状态|标签金额分区、取消不扣款|
|报表与债务|个人现金、收入、支出、资产负债|展开／关闭／点选贷款|旁观者只看自己的表|不重复渲染、不溢出|
|快车道与破产|fastBase、fastGain、重整状态|投资／确认／清算|税、诉讼、失败、出局|各状态的收入、贷款和按钮|
|棋盘查看|当前表单草稿及卡片|查看棋盘／返回|新决策恢复控件|不结算、不丢输入、无遮挡|
|结束与恢复|胜负、会话、持久化状态|退出／恢复会话|断网、失效会话|恢复不重复结算|

坐标事实以reference-layout-data.js为准，原素材来源见assets/reference/SOURCES.json。此表是状态规格索引，逐状态批准截图与录屏仍需补齐；现有截图不能代替所有异常状态的设计。
