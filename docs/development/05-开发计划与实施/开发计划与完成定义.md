# 开发任务与完成定义

|开发子阶段|输入|实现交付|必须留下的记录|
|---|---|---|---|
|环境与骨架|范围、技术方案|可启动服务／离线构建|环境说明、启动与构建记录|
|规则和数据|规则表、字段契约|引擎、职业与牌堆|来源映射、独立数值测试|
|纵向切片|一个完整用户流程|开局→掷骰→买卖→结算→保存|联调记录、场景测试、缺陷单|
|单机完整闭环|全部核心状态|内外圈、借还、破产、胜负|功能清单、存档与回归证据|
|联机与恢复|接口／指令契约|权威服务、轮序、会话恢复|契约、并发与重试测试|
|内容与表现|页面规格、资源清单|文案、图像、音效、动效|素材版本、页面截图和差异|
|稳定与候选|缺陷台账、验收门槛|可交付候选包|修复影响、回归、包SHA|

当前实现已涉及以上各子阶段，但历史文档和评审并不齐全。当前待办优先级：真实file入口验证、参考版次与规则差异结论、完整页面基线、API／存档Schema、浏览器矩阵、最终UAT。实际人员和承诺日期尚未分配，不用虚构排期。

每个任务应含ID、需求ID、输入文档版本、负责人、依赖、输出、通过条件、测试与提交。完成定义：实现满足约定条件；有针对性及必要回归；代码和契约同步；缺陷状态明确；受测构建可定位。功能完成、QA通过、产品批准、用户验收分别记录。
